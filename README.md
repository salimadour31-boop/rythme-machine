# Rythme Machine 🥁

Boîte à rythme libre, 100 % dans le navigateur. Séquenceur 16 pas avec sons synthétisés (kick, snare, hi-hat) via Web Audio API. Aucune installation, aucun envoi de données, aucun compte.

**Démo :** https://salimadour31-boop.github.io/rythme-machine/

## Fonctionnalités
- Grille 16 pas × 3 pistes (Kick, Caisse claire, Charleston)
- Sons 100 % synthétisés (oscillateurs + bruit blanc)
- Contrôle BPM (60–180)
- Lecture / arrêt avec indicateur de pas courant
- Export du motif en JSON
- Multilingue : Français, English, Taqbaylit
- Responsive, thème sombre, polices système
- Licence MIT

## Usage
Ouvrir la démo ou cloner et ouvrir `index.html` dans un navigateur moderne.

```bash
git clone https://github.com/salimadour31-boop/rythme-machine.git
```
